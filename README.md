# Управление проектом (Kanban)

## Правила доски
1. **WIP-лимит:** Не более 2 задач в колонке `In Progress` на одного исполнителя.
2. **Приоритеты:** Задачи берутся строго по приоритету (`P0` -> `P3`).
3. **Зависимости:** Заблокированные задачи помечаются лейблом `status: blocked` с указанием номера блокирующей задачи (`Blocked by #...`).
